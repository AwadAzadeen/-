# لمسة إبداع للديكورات الحديثة — موقع تعريفي

## الملفات
- `index.html`: محتوى الموقع العربي.
- `css/style.css`: التصميم والتجاوب مع الجوال والكمبيوتر.
- `js/main.js`: القائمة، تصفية المعرض، تكبير الصور، ونموذج واتساب.
- `images/`: مجلد مخصص لإضافة صور الأعمال الحقيقية.

## تجربة الموقع
افتح `index.html` في المتصفح. يحتاج الاتصال بالإنترنت لتحميل الخط والصور الخارجية الحالية.

## قبل النشر
1. استبدل صور المعرض الإلهامية بصور أعمالك الحقيقية، وعدّل النصوص حسب خدماتك الفعلية.
2. تأكد من رقم واتساب ورابط خرائط Google.
3. اختبر نموذج الطلب على الجوال.
4. ارفع الملفات إلى استضافة تدعم المواقع الثابتة، مثل GitHub Pages أو Netlify أو استضافة موقعك الحالية.

## ملاحظات
- نموذج الطلب يفتح واتساب برسالة جاهزة؛ لا يخزن الطلبات في قاعدة بيانات.
- الصور الحالية من Unsplash لأغراض العرض فقط، وليست صورًا توثيقية لأعمال النشاط.
- اسم النطاق يحتاج شراءً وربطًا منفصلًا إذا رغبت في استخدام نطاق خاص.
